# 🎯 나만의 퀴즈 게임 (Python Console)

Python 기본 문법과 객체 지향(클래스), 파일 입출력(JSON)을 활용하여 만든 터미널 기반 퀴즈 게임입니다.

## 📖 프로젝트 개요
터미널에서 메뉴를 선택하여 퀴즈를 풀고, 나만의 퀴즈를 직접 추가할 수 있는 대화형 콘솔 프로그램입니다. Git을 통한 브랜치 전략과 기능 단위 커밋을 적용하며 협업 워크플로우를 실습하는 것이 주된 목표입니다.

## 💡 퀴즈 주제 선정 이유
* **주제:** 파이썬 및 프로그래밍 상식
* **선정 이유:** 파이썬으로 파이썬 관련 퀴즈 게임을 만들면 언어에 대한 이해도도 높아지고, 스스로 복습하기에 매우 좋은 주제라고 생각하여 선정했습니다. (수정 가능)

## 🚀 실행 방법
터미널(또는 명령 프롬프트)에서 아래 명령어를 입력하여 실행합니다.
```bash
python main.py
```

## ✅ 기능 목록
- **퀴즈 풀기:** 저장된 퀴즈를 차례대로 풀고 정답/오답 여부와 최종 점수를 확인합니다.
- **퀴즈 추가:** 사용자가 직접 문제, 선택지, 정답을 입력하여 새로운 퀴즈를 등록합니다.
- **퀴즈 목록:** 현재 저장된 전체 퀴즈 리스트를 조회합니다.
- **점수 확인:** 지금까지 기록된 최고 점수를 확인합니다.

## 📁 파일 구조
- `main.py` : 프로그램 진입점(Entry Point), 메인 메뉴 흐름 및 핵심 클래스(`Quiz`, `QuizGame`) 정의
- `state.json` : 퀴즈 데이터 및 최고 점수를 영구적으로 저장하는 JSON 파일
- `README.md` : 프로젝트 설명 문서

## 💾 데이터 파일 설명 (state.json)
프로그램의 데이터 영속성을 위해 루트 경로에 `state.json` 파일을 자동 생성하고 관리합니다. 파일이 손상되었거나 없을 경우, 프로그램이 실행 시 기본 데이터로 자동 복구합니다.
* **구조 (스키마):**
  * `quizzes` (리스트): 각 퀴즈 정보(문제, 선택지, 정답 번호)를 담은 딕셔너리의 배열
  * `best_score` (정수): 역대 최고 득점
